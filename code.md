AirLab aims to open source our code to help advance academia and the state of the art in robotics. We believe that sharing our software openly accelerates research, enables reproducibility, and empowers the broader robotics community to build on our work.

## AirStack

AirStack is our open source software stack for autonomous robots. It provides a modular, ROS 2-based framework spanning autonomy, simulation, and ground control — everything you need to develop, simulate, and deploy robot autonomy, developed and field-tested by the AirLab.
